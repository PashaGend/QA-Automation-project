מה זה בכלל "שורת פקודה"?
תוכנה שבה כותבים פקודות בטקסט במקום ללחוץ על כפתורים. נשמע מפחיד — בפועל: מעתיקים טקסט, מדביקים, לוחצים Enter. זהו כל הסוד.
1

שלוש התקנות חד-פעמיות

🐳

Docker Desktop

התוכנה שמריצה את כל הפרויקט, בלי להתקין שום דבר אחר על המחשב. חייבת להישאר פתוחה ברקע.

להורדה ←
🟢

Node.js

מריץ קטע קוד קטן אחד שהפרויקט צריך. בוחרים בגרסה המומלצת (LTS).

להורדה ←
📦

Git

מעתיק את הקוד מ-GitHub למחשב. אפשר ללחוץ "הבא" בכל המסכים בלי לשנות כלום.

להורדה ←

כל אחת מותקנת כמו תוכנה רגילה: מורידים, פותחים, לוחצים "הבא" עד הסוף. רק את Docker Desktop צריך לפתוח ולהשאיר פתוח — השתיים האחרות עובדות ברקע אוטומטית.

🚀 יש לכם כבר Git? אפשר לדלג על ההתקנות הידניות: אחרי שלב 3 למטה (ה-clone), יש בפרויקט סקריפט scripts\install-prereqs.ps1 שמתקין את Node.js ו-Docker Desktop לבד (מריצים אותו כ-Administrator). עדיין צריך לפתוח את Docker Desktop ידנית פעם אחת בסוף.

2

פותחים שורת פקודה

ב-Windows: לוחצים על כפתור Start, מקלידים PowerShell, ולוחצים Enter על התוצאה שמופיעה. ייפתח חלון כהה עם טקסט — זה הוא.

3

מעתיקים-מדביקים שלוש שורות

אחת-אחת: לוחצים על כפתור העתק, עוברים לחלון השחור, מדביקים (Ctrl+V או קליק ימני → Paste), לוחצים Enter, מחכים שהשורה הבאה של ">" תופיע, וממשיכים לפקודה הבאה.

1 git clone https://github.com/PashaGend/mundial-qa-automation.git
2 cd mundial-qa-automation
3 npm run setup
4

מה קורה עכשיו

המון טקסט יתחיל לרוץ במסך — זה תקין. זה מוריד ובונה הכל אוטומטית: בפעם הראשונה לוקח כ-2–3 דקות.

לא נוגעים בכלום ולא סוגרים את החלון עד שהטקסט מפסיק לזוז ומופיעה שוב שורת פקודה ריקה.
