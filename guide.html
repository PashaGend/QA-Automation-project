⚡ מהיר

קובץ אחד

מתקין Git/Node/Docker אם חסרים, מרים את הסביבה, פותח את האפליקציה. אידמפוטנטי — אפשר להריץ שוב בלי נזק.

1 install.bat →
2 powershell -ExecutionPolicy Bypass -File .\install.bat

הקישור פותח raw code בדפדפן, לא מוריד ישירות — Ctrl+S לשמור, לוודא שהסיומת נשארת .bat (לא .txt/.html שהדפדפן אוהב להציע). דורש אישור UAC (מתקין תוכנות). SmartScreen עלול להתריע — More info → Run anyway. גם install.ps1 קיים, ללא ה-polyglot batch.

1 install.command →
2 chmod +x ~/Desktop/install.command

הקישור פותח raw code בדפדפן — Cmd+S לשמור, לוודא שהסיומת נשארת .command. דאבל-קליק דרך Finder. הורדה מהדפדפן מאפסת את ה-execute bit (ולכן ה-chmod), ו-Gatekeeper יחסום בפעם הראשונה — Right-click → Open → Open. משתמש ב-Homebrew.

ידני

דרושים מראש (הקובץ האחד למעלה מתקין אותם לבד — כאן לא): Git · Node.js (LTS) · Docker Desktop (צריך להישאר פתוח ברקע). או בשורת פקודה:

🪟 winget install Git.Git OpenJS.NodeJS.LTS Docker.DockerDesktop
🍎 brew install git node && brew install --cask docker

(winget דורש Administrator; brew דורש Homebrew מותקן מראש. ר' גם scripts/install-prereqs.ps1 בפרויקט.)

1 git clone https://github.com/PashaGend/mundial-qa-automation.git
2 cd mundial-qa-automation && npm run setup

setup משכפל את Mondial2026 כ-sibling אוטומטית (אם חסר), ואז מריץ env:up (npm install → docker compose up --build → ניקוי test users). תוצאה זהה לחלוטין לקובץ האחד למעלה.

הסרה

🪟 uninstall.bat →
🍎 uninstall.command →

שמירה — אותו Ctrl+S/Cmd+S כמו קובץ ההתקנה, לוודא סיומת מדויקת. שומרים באותה תיקייה כמו קובץ ההתקנה. מוריד containers/volumes/images של הפרויקט + את קבצי ה-install/uninstall עצמם (כולל את עצמו). שואל לפני מחיקת התיקיות. לא נוגע ב-Git/Node/Docker עצמם.
