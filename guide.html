מה זה בכלל "שורת פקודה"?
תוכנה שבה כותבים פקודות בטקסט במקום ללחוץ על כפתורים. נשמע מפחיד — בפועל: מעתיקים טקסט, מדביקים, לוחצים Enter. זהו כל הסוד.

הדרך הכי מהירה — קובץ אחד, דאבל-קליק

בלי Docker? בלי Git? בלי Node? לא משנה — קובץ אחד עושה הכל: מתקין מה שחסר, מוריד את הפרויקט, ומריץ אותו.

👇 הדרך הזו מחליפה לגמרי את כל 5 השלבים "שלב-שלב" למטה — בסופה האפליקציה כבר רצה ב-localhost:8080, בדיוק כמו בסוף שלב 5. קוראים/עושים רק אחד מהשניים, לא את שניהם. הבונוס בסוף המדריך (איך מריצים את הבדיקות) רלוונטי בכל מקרה, לא משנה באיזו דרך התחלתם.

1. לוחצים כאן: install.bat ← — ייפתח טאב חדש עם המון קוד. זה תקין, זה לא אמור "להפעיל" כלום עדיין.

2. בטאב הזה (עם הקוד), לוחצים Ctrl+S כדי לשמור אותו כקובץ. בחלון השמירה שנפתח: בוחרים איפה לשמור (למשל שולחן העבודה), ובשדה השם מוודאים שכתוב בדיוק install.bat — לפעמים הדפדפן מציע לבד install.txt או install.html, וזה לא יעבוד. לוחצים "שמור".

3. דאבל-קליק על הקובץ ששמרתם. ייתכן ש-Windows יציג אזהרה כחולה ("Windows protected your PC") — זה קורה לכל קובץ שמורידים מהאינטרנט ולא חתום; לוחצים More info ואז Run anyway.

4. ייפתח חלון הרשאות (UAC) — לוחצים "כן". ייפתח חלון שחור עם טקסט טכני שרץ — זה תקין ומוסבר בתוך החלון עצמו, לא צריך לקרוא או להקליד שם כלום. מפה הכל אוטומטי.

אפשר להריץ שוב בלי חשש — כל שלב מדלג על מה שכבר קיים. מעדיפים להריץ מתוך PowerShell ולא דאבל-קליק? יש גם install.ps1 — אותו קובץ בדיוק, בלי העטיפה של דאבל-קליק.

⚠️ מגבלה אחת אמיתית: אם ל-Windows שלכם מעולם לא הופעלה וירטואליזציה (WSL2), Docker ידרוש הפעלה מחדש חד-פעמית של המחשב. הסקריפט מזהה את זה ואומר לכם במפורש — מפעילים מחדש ומריצים שוב דאבל-קליק על אותו קובץ.

1. לוחצים כאן: install.command ← — ייפתח טאב חדש עם המון קוד. זה תקין, זה לא אמור "להפעיל" כלום עדיין.

2. בטאב הזה (עם הקוד), Cmd+S כדי לשמור כקובץ. בחלון השמירה: בוחרים איפה (למשל שולחן העבודה), ובשדה השם מוודאים שכתוב בדיוק install.command — לא .txt או .html.

3. פותחים Terminal (⌘+רווח, מקלידים Terminal, Enter) ומריצים פעם אחת בלבד, כדי לתת הרשאת הרצה (קבצים שיורדים מהאינטרנט לא מקבלים אותה אוטומטית):

1 chmod +x ~/Desktop/install.command

4. דאבל-קליק על הקובץ ב-Finder. macOS כנראה יחסום בפעם הראשונה ("cannot be opened because it is from an unidentified developer") — קליק ימני על הקובץ → Open → Open שוב באזהרה. ייפתח חלון Terminal עם טקסט טכני שרץ — זה תקין ומוסבר בתוך החלון עצמו, לא צריך לקרוא או להקליד שם כלום. מפה הכל אוטומטי (ייתכן שיבקש את הסיסמה שלכם בשביל Homebrew).

אפשר להריץ שוב בלי חשש — כל שלב מדלג על מה שכבר קיים.

2 cd mundial-qa-automation
3 npm run setup

רוצים גם להריץ את הבדיקות?

זה לא חלק מההתקנה — האפליקציה כבר רצה ועובדת בלי השלב הזה. זה מריץ את 41 הבדיקות האוטומטיות של הפרויקט (ממשק משתמש, API, ושאילתות SQL) מול האפליקציה שכבר רצה, בשביל מי שסקרן.

1. פותחים שורת פקודה — ב-Windows: Start, מקלידים PowerShell, Enter (שלב 2 למעלה). ב-Mac: ⌘+רווח, מקלידים Terminal, Enter.

2. עוברים לתיקיית הפרויקט. אם השתמשתם בקובץ הדאבל-קליק (install.bat/install.command), התיקייה mundial-qa-automation נוצרה **ליד** הקובץ ששמרתם — למשל אם שמרתם על שולחן העבודה:

🪟 cd $HOME\Desktop\mundial-qa-automation
🍎 cd ~/Desktop/mundial-qa-automation

(שמרתם במקום אחר? אותו רעיון — cd לאותה תיקייה, ואז mundial-qa-automation. עשיתם את ה-git clone בעצמכם בשיטה הידנית למטה? זו אותה תיקייה שנכנסתם אליה שם עם cd.)

3. מריצים:

1 docker compose --env-file .env.docker run --rm tests

4. מה לצפות לראות: כמה שניות של טקסט הכנה, ואז רשימה של שמות בדיקות שרצות אחת-אחת (למשל [1/41] tests\ui\login.spec.ts ...) — זה לוקח בערך 15–30 שניות. בסוף אמורה להופיע שורה ירוקה: 41 passed. אם משהו נכשל (אדום) — זה לא קשור להתקנה עצמה; כדאי לבדוק קודם שהאפליקציה עדיין נגישה ב-localhost:8080.

בונוס · אופציונלי

רוצים להסיר הכל בסוף?

יש קובץ מקביל לקובץ ההתקנה, שמבטל אותו: מוריד containers/volumes/images של הפרויקט הזה בלבד. לא מסיר את Git, Node.js או Docker Desktop עצמם — אלה כלים משותפים שאולי תצטרכו למשהו אחר.

1. מורידים אותו בדיוק כמו קובץ ההתקנה (לוחצים → Ctrl+S/Cmd+S → מוודאים שהשם נשאר מדויק):

🪟 uninstall.bat →
🍎 uninstall.command →

2. שומרים אותו באותה תיקייה שבה שמרתם את קובץ ההתקנה בשלב 1 (ליד mundial-qa-automation ו-Mondial2026) — לא בתוך אחת מהתיקיות עצמן.

3. (ב-Mac בלבד) בדיוק כמו בהתקנה — הורדה מהדפדפן מאפסת את הרשאת ההרצה, אז פותחים Terminal ונותנים אותה פעם אחת (מחליפים נתיב אם שמרתם במקום אחר מהדוגמה בשלב ההתקנה):

1 chmod +x ~/Desktop/uninstall.command

4. דאבל-קליק (ב-Mac: אותו תהליך "Open" כמו בהתקנה). נשאל אם למחוק גם את תיקיות הפרויקט עצמן — ברירת המחדל היא לא (שומר על שינויים מקומיים שעשיתם). אם לא נגעתם בקוד, אפשר לענות כן.

לעצור הכל זמנית בלי להסיר כלום: docker compose down (מריצים מתוך אותה תיקייה).
פרטים טכניים נוספים — ב-README של הפרויקט ב-GitHub.
