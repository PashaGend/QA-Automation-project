QA Automation Environment - Mundial2026

Docker + Postgres/PostgREST + the app + 41 tests (UI/API/SQL), locally, one command

Two alternative ways to bring up the environment — not in sequence: "One file" (installs everything, including dependencies) or "Manual" (if Git/Node/Docker are already installed, or the one-file option didn't work).

⚡ Fast

One file

Installs Git/Node/Docker if missing, brings up the environment, opens the app. Idempotent — safe to run again.

1 ⬇️ Download install.bat
2 powershell -ExecutionPolicy Bypass -File .\install.bat

Needs UAC approval (installing software). SmartScreen may warn — More info → Run anyway. install.ps1 also exists, without the polyglot batch.

1 ⬇️ Download install.command
2 chmod +x ~/Desktop/install.command

Double-click it from Finder once downloaded. Downloading resets the execute bit (hence the chmod), and Gatekeeper will block it the first time — Right-click → Open → Open. Uses Homebrew.

Manual

Prerequisites (the one-file option above installs them for you — this path doesn't): Git · Node.js (LTS) · Docker Desktop (needs to stay running in the background). Or from the command line:

1 winget install Git.Git OpenJS.NodeJS.LTS Docker.DockerDesktop

Run from PowerShell as Administrator (Start → type PowerShell → right-click → Run as administrator) — winget fails without it.

1 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
2 brew install git node && brew install --cask docker

Line 1 — Homebrew itself, if you don't already have it (asks for your Mac password). Skip it if it's already installed.

1 git clone https://github.com/PashaGend/mundial-qa-automation.git
2 cd mundial-qa-automation && npm run setup

setup clones Mondial2026 as a sibling automatically (if it's missing), then runs env:up (npm install → docker compose up --build → cleans up test users). Unlike the one-file option above, it doesn't open a browser automatically — once it finishes (you get an empty prompt back), open localhost:8080 yourself.

optional

Tests

1 docker compose --env-file .env.docker run --rm tests

41 tests (Playwright) — UI, API, SQL. ~20s. 41 passed at the end means it's all good.

optional

Uninstall

1 ⬇️ Download uninstall.bat
1 ⬇️ Download uninstall.command

Save it in the same folder as the installer. Removes the project's containers/volumes/images plus the install/uninstall files themselves (including itself). Asks before deleting the folders. Doesn't touch Git/Node/Docker themselves.

docker compose down — temporary stop, no deletion. npm run status — actually checks everything is running (doesn't assume).
